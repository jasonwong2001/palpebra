# Roadmap

Ideas for after 1.0. Nothing here is promised; please open an issue to talk one through before starting work.

- **Stay quiet during calls, screen sharing and presentations,** and respect Focus modes. For now, pause reminders from the menu bar.
- **A one-click 20-20-20 setup:** a 20-second break every 20 minutes. You can already type those values in Rules.
- **Keep fatigue across restarts.** The meter starts at 0% each time Palpebra opens.
- **Cover displays connected during a break.**
- **Violet everywhere:** an asset catalog so focus rings, text selection and menu highlights use Palpebra's color too. It has to be compiled with Xcode's asset compiler, which the Command Line Tools don't include.
- **Swift Charts** for Analysis.
- **A Homebrew cask,** if Homebrew accepts apps that aren't notarized.
- **App Sandbox:** if idle time, the global shortcut, notifications and Open at login all work sandboxed, macOS itself would enforce that Palpebra never connects to the network.
- **Translations** with String Catalogs. The interface is English-only for now.

## Not planned

- **Automatic updates.** Palpebra connects nowhere. If updates are ever added, they'll be opt-in; until then, watch the repository's releases.
