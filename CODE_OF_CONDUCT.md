# Code of Conduct

The Palpebra community adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) by reference. Its pledge, standards, scope, enforcement responsibilities and enforcement guidelines apply to participation in this project, including its issues, pull requests and other community spaces.

Report unacceptable behavior privately to the project maintainers, using the contact details on their GitHub profiles. For abusive content, you can also use GitHub's **Report content** option, which reaches GitHub staff. Maintainers will review reports promptly and fairly and respect the privacy and security of the reporter. Please do not post private reports in public issues.
